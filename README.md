# PrayerSG

A responsive Singapore prayer-times display for a landscape digital-signage screen.

## Features
- Six daily milestones: Subuh, Syuruk, Zohor, Asar, Maghrib and Isyak
- Singapore local clock and date
- Countdown to the next prayer
- Current prayer period highlighting
- Automatic refresh every 30 minutes
- Cached timetable fallback if the API is temporarily unavailable
- Responsive 3-column × 2-row prayer grid; switches to 2 columns on very narrow screens

## Data source
[PrayerTimes.sg API](https://api.prayertimes.sg/api/v1/prayer-times/today)

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose branch **main** and folder **/(root)**, then Save.
4. Wait for the Pages URL to appear in the Pages section.

The site is static HTML/CSS/JavaScript and requires no build step.
